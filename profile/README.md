# Platzeo

Online table reservations for restaurants, made in Germany.

Restaurants get their own booking page at `<name>.platzeo.de`, a widget and a
WordPress plugin for their own website, an admin for reservations, tables,
guests, events and loyalty cards, and an Android app for the team on the
floor. Partner apps connect through an API with OAuth, and AI assistants
through an MCP server.

- Website: [platzeo.de](https://www.platzeo.de)
- System status: [status.platzeo.de](https://status.platzeo.de)
- WordPress plugin: [platzeo.de/wordpress-plugin](https://www.platzeo.de/wordpress-plugin)
- API reference: [platzeo.de/api-referenz](https://www.platzeo.de/api-referenz)
